# Akramul Hoque — Portfolio

Portfolio of **Akramul Hoque (Akram)**, a full-stack software engineer in Dhaka with 4+ years of experience.

**Live site:** https://akramulhoque1320.github.io/akh/

## Features

- **Time-of-day hero:** the sky, accent colour and greeting change to morning, afternoon, evening or night, based on the visitor's local clock
- A typed headline with key-click sound, started from a "tap to enter" screen
- Experience timeline, featured client work with live-site previews and filterable project cards
- A live Dhaka clock, a contact section and a downloadable resume
- Responsive on phones, tablets and desktops, with keyboard focus styles and `prefers-reduced-motion` support

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```
